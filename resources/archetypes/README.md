# Archetype Adaptation Guides

The course's default path reads B2B SaaS. The method is identical for everyone — hypothesis, threshold, wallet — but WHAT counts as a wallet opening differs by archetype. Find yours, read the one-pager, translate your weekly bars accordingly. Everything else in the course stays as-is.

| Archetype | Your wallet-equivalents | Guide |
|---|---|---|
| B2C / consumer app | paid downloads, subscriptions, pre-orders | [B2C.md](B2C.pdf) |
| Marketplace | supply commitments + first take-rate euros | [Marketplace.md](Marketplace.pdf) |
| Deep tech / research | paid pilots, LOIs with money attached, grants (with caveats) | [DeepTech.md](DeepTech.pdf) |
| Hardware | deposits and pre-orders — never applause | [Hardware.md](Hardware.pdf) |
