# Module 06 — Prototyping with AI

> **Core question:** What is the fastest thing you can build to learn?

**Session flow:** Intro & check-in (5′) → Recap M05 + homework debrief (10′) → Lecture: the ideas (60′) → Case discussion (30′) → Workshop (90′) → Wrap-up & homework (10′)

## The Ideas

1. Vibe-coding: AI pair-building turns months into days
2. The no-code/low-code stack: Lovable, Make, Airtable and friends
3. Just enough architecture: APIs, webhooks, deployment that survives iteration
4. Build to learn, not to last — prototypes are disposable

**This week's bar:** deployed prototype + 10 non-friend reactions logged + 2 fixes shipped. Rules: [Grading & Revenue Ladder](../../resources/GRADING_RUBRIC.pdf).
