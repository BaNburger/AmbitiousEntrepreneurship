# Module 07 — The Kill Decision

> **Core question:** Why should this startup die?

**Session flow:** Intro & check-in (5′) → Recap M06 + homework debrief (10′) → Lecture: the ideas (60′) → Case discussion (30′) → Workshop (90′) → Wrap-up & homework (10′)

## The Ideas

1. Kill your darlings: Google X's 'monkey first' mindset
2. Pre-mortem: find the cause of death before it happens
3. Test the riskiest assumption, not the easiest one
4. Go / Pivot / Kill — decide with criteria you committed to in advance

**This week's bar:** GPK scorecard + provisional verdict + monkey-first test run. Rules: [Grading & Revenue Ladder](../../resources/GRADING_RUBRIC.md).
