# Workshop 00 — Startup Autopsy

> Module 00 · Kickoff — No-Bullshit Entrepreneurship · 90 minutes

## The 90 Minutes

| Time | Block | What happens |
|---|---|---|
| 5m | **Scene Setting** | Startup graveyard framing + case study distribution |
| 20m | **Autopsy Phase** | Teams analyze assigned failed startup case study |
| 15m | **Report Out** | 90 seconds per team, hard-timed: cause of death → pattern on whiteboard |
| 15m | **Debrief** | Cause-of-death patterns → which kill criterion would have fired, in which week? |
| 25m | **First Signal** | Everyone drafts + SENDS 3 messages to real people about a frustration they've observed. Not friends-for-comfort — real signal. |
| 10m | **Setup** | Student Toolkit + commit to 3 problem hypotheses |

## Discussion Sparks

- “What’s the difference between a startup that dies at €10M revenue vs €0?”
- “If you could only save ONE of these startups, which one and how?”
- “Why do smart TUM engineers keep building things nobody wants?”

## Must Produce — Today’s Deliverable

Completed autopsy sheet + 3 personal problem hypotheses + 3 First-Signal messages SENT

**Kill criteria:** You can’t name a single real human who has this problem
