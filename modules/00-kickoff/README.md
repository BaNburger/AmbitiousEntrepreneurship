# Module 00 — Kickoff — No-Bullshit Entrepreneurship

> **Core question:** What kills startups — and what will this course demand from you?

**Session flow:** Intro & check-in (5′) → Lecture: the ideas (60′) → Case discussion (30′) → Workshop (90′) → Wrap-up & homework (10′)

## The Ideas

1. Startups die of self-inflicted wounds: they build things nobody wants
2. Evidence beats opinions — the validation mindset that runs this course
3. Speed is the only advantage you have over incumbents
4. The course contract: real users, real revenue, kill criteria every week

**This week's bar:** 3 problem hypotheses + 2 real conversations (named, quoted). Anti-fake rules: [Grading & Revenue Ladder](../../resources/GRADING_RUBRIC.md).
