# Module 05 — The Solution Space

> **Core question:** Of all the ways to solve this problem, why this one?

**Session flow:** Intro & check-in (5′) → Recap M04 + homework debrief (10′) → Lecture: the ideas (60′) → Case discussion (30′) → Workshop (90′) → Wrap-up & homework (10′)

## The Ideas

1. Diverge, then converge — solution ideation is a numbers game first
2. The 10x test: marginally better always loses to the status quo
3. Scope the MVP: cut features until it hurts, then cut once more
4. Click dummies: sell the promise before you build the product

**This week's bar:** 10x scorecard (4 gates) + MVP spec + deployed Weekend Build. Rules: [Grading & Revenue Ladder](../../resources/GRADING_RUBRIC.md).
