# Workshop 05 — 10x or Die

> Module 05 · The Solution Space · 90 minutes

## The 90 Minutes

| Time | Block | What happens |
|---|---|---|
| 10m | **Data Review (go/pivot fork)** | Threshold read out loud next to the number → GO converges, weak data forks to pivot type 1/2. What converted, what didn’t? |
| 15m | **10x Value Test** | Score your solution on all 4 gates of the 10x Test |
| 25m | **MVP Sketch** | Draw the absolute minimum that delivers the 10x value |
| 25m | **Build Plan** | What can you build THIS WEEKEND? Stack, tools, timeline |
| 15m | **Weekend Commit** | Public commitment: deploy working prototype by Sunday |

## Discussion Sparks

- “If you can’t state your 10x value in under 10 words, go back to the problem.”
- “Claude + Cursor + Vercel = deployed product by Sunday. No excuses.”
- “What’s the ONE thing your MVP does that makes people say ‘holy shit’?”

## Must Produce — Today’s Deliverable

10x scorecard + MVP spec + Weekend Build commitment

**Kill criteria:** You can’t pass Gate 1 of the 10x Test: state value in <10 words
