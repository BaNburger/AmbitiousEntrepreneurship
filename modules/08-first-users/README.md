# Module 08 — Finding First Users

> **Core question:** Who are your first ten customers — by name?

**Session flow:** Intro & check-in (5′) → Recap M07 + homework debrief (10′) → Lecture: the ideas (60′) → Case discussion (30′) → Workshop (90′) → Wrap-up & homework (10′)

## The Ideas

1. Do things that don't scale: the Collison installation
2. Founder-led sales: outreach that actually gets answered
3. The first-user funnel: from stranger to activated user
4. Charge early — the €1 test separates users from fans

**This week's bar:** first outside-€ (pass) · 3 paying users (stretch) — dashboard-verified. Rules: [Grading & Revenue Ladder](../../resources/GRADING_RUBRIC.md).
