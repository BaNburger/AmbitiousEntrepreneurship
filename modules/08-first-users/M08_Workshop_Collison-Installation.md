# Workshop 08 — The Collison Installation

> Module 08 · Finding First Users · 90 minutes

## The 90 Minutes

| Time | Block | What happens |
|---|---|---|
| 10m | **Target List** | Start from your Module 06 10-person outreach list and upgrade it: every name needs a real pain AND budget authority (or access to it) |
| 20m | **Outreach Craft** | Write a personalized message for each person — name a real pilot price (€300–500 anchors; a €1 anchor kills you) |
| 20m | **Sales Role-Play** | Practice asking for money. Out loud. With a partner. |
| 20m | **Send LIVE** | Send all 10 outreach messages RIGHT NOW in class |
| 20m | **Tracking + Objection Prep** | Replies won't arrive in-session: set up response tracking, write answers to the 3 objections you fear most, commit to 48h follow-ups |

## Discussion Sparks

- “If you can’t name 10 specific humans, you have a fantasy, not a market.”
- “The Collison brothers asked ‘can I install this for you right now?’ Do that.”
- “Most technical founders have never asked anyone for money. That ends today.”

## Must Produce — Today’s Deliverable

10 outreach messages SENT + response tracking started

**Kill criteria:** You sent 10 messages and got zero replies in 48 hours
